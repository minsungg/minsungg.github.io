# 알라딘 사용자 리뷰 기반 UI/UX 문제 분석
**POC 클리닉 \| 데이터 분석 및 서비스 문제 검증**
### 프로젝트 개요
알라딘 서비스의 UI/UX 개선 방향을 탐색하기 위해 Google Play Store 사용자 리뷰를 수집하고, LLM을 활용해 리뷰 내용을 범주화하여 사용자 불편 사항을 분석했습니다.

## 1. Problem — 사용자 문제를 확인할 데이터의 부재
알라딘이 공식적으로 제공하는 공개 데이터는 주로 재무 정보에 집중되어 있어, 사용자가 서비스에서 실제로 겪는 UI/UX 문제를 파악하기 어려웠습니다.
이에 다음과 같은 질문을 정의했습니다.
- 사용자 반응을 확인하기 위해 어떤 데이터를 수집해야 하는가?
- 자연어로 작성된 리뷰를 어떻게 일관된 기준으로 분류하고 분석할 수 있는가?
특히 사용자 리뷰는 자유로운 문장으로 작성되므로, 단순한 키워드 검색만으로는 여러 불편 사항을 일관되게 분류하기 어렵다고 판단했습니다.
## 2. Approach — 사용자 리뷰 수집 및 LLM 기반 범주화
### ① 사용자 반응 데이터 수집
Google Play Store 리뷰를 분석 대상으로 선정했습니다.
선정 이유는 다음과 같습니다.
- 최신 리뷰와 관련도 높은 리뷰를 확인할 수 있음
- 사용자들이 앱을 직접 사용하면서 겪은 문제를 서술함
- 알라딘 앱 사용 경험을 바탕으로 한 UI/UX 관련 의견을 확인할 수 있음
관련도 순으로 리뷰 500개를 수집한 후, **1\~2점의 부정적 리뷰 350개를 선별하여 분석**했습니다.
### ② 자연어 리뷰의 범주형 데이터 변환
자연어 리뷰를 통계적으로 분석하기 위해 LLM을 활용해 각 리뷰를 사전에 정의한 문제 범주로 분류했습니다.
분석 과정에서 단순히 Gemini나 ChatGPT 웹 서비스에 리뷰를 입력하는 방식 대신, **LLM API를 이용해 리뷰를 한 건씩 처리하고 판단 근거와 분류 결과를 함께 기록**하도록 구성했습니다.
이를 통해 각 분류 결과를 검토하고, 분석 과정의 추적 가능성을 높이고자 했습니다.
### ③ 모델 선택 및 실행 환경
한국어 리뷰 분석 성능을 고려하여 비교적 큰 언어 모델을 양자화하여 로드했습니다.
- Qwen2.5-7B-Instruct
- 4비트 양자화
- LLM API를 통한 리뷰별 분석
- 판단 근거와 분류 결과 저장
여기서 양자화된 언어 모델의 한국어 작성 성능이 영어에 비해 확연히 떨어지는 것이 확인되어 판단 근거 및 분류에서 영어로 문장을 작성하도록 했습니다.
## 3. Result — UI/UX 관련 불편 사항 분석
### UI/UX 문제의 주요 비중 확인
부정적 리뷰 중 약 **31.7%가 UI/UX 미흡으로 인한 편의성 저하**로 분류되었습니다.
주요 사례는 다음과 같습니다.
- 장바구니 아이콘 및 메뉴 클릭 문제
- 로딩 피드백 부족
- 보관함·구매함·장바구니로 이어지는 복잡한 탐색 동선
- 결제 과정에서 장바구니 상품이 사라지는 문제
이를 통해 사용자 리뷰에서 반복적으로 언급되는 UI/UX 관련 불편 사항을 범주별로 확인했습니다.
### 문제 빈도와 부정적 평가 비율 비교
범주별 발생 빈도와 1점 리뷰 비율을 비교한 결과:
- **터치/버튼 반응 불가:** 46건, 1점 비율 87.0%
- **검색/동선 탐색 불편:** 37건, 1점 비율 86.5%
두 범주는 발생 빈도와 1점 비율이 모두 높게 나타나, 추가적인 UI/UX 검토가 필요한 영역으로 확인되었습니다.
LLM이 분류한 리뷰를 사람이 직접 원문과 대조하여 분류 결과의 적절성을 확인했습니다. 분류 기준과 실제 리뷰 내용이 일치하는지 검토하고, 분류 결과를 분석 자료로 활용할 수 있는지 판단했습니다.
## 4. Contribution — 본인의 기여
- 사용자 반응을 확인하기 위한 데이터 출처 선정
- Google Play Store 리뷰 수집 및 부정적 리뷰 선별
- 자연어 리뷰를 범주형 데이터로 변환하는 분석 방법 설계
- LLM API를 활용한 리뷰별 판단 근거 및 분류 결과 저장
- 분석 데이터를 기반으로 UI/UX 문제의 발생 빈도와 심각도 비교
- 분석 결과 시각화 및 서비스 개선 검토를 위한 근거 자료 작성
## 5. Lesson — 배운 점
사용자 경험과 관련된 문제를 파악할 때, 서비스에서 직접 제공하는 데이터뿐 아니라 사용자 리뷰와 같은 비정형 데이터도 분석 대상으로 활용할 수 있음을 경험했습니다.
또한 자연어 데이터를 범주형 데이터로 변환할 때는 단순히 분류 결과를 얻는 것뿐 아니라 **분류 기준과 판단 근거를 함께 관리하는 것이 중요하다**는 점을 배웠습니다.
