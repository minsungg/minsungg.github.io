자동 미분의 구현 원리와 PyTorch의 내부 동작을 이해하기 위해 읽은 책입니다. 간단한 계산 그래프 구현에서 시작해 자동 미분과 신경망 구현으로 확장하며, python의 OOP 기능을 활용해 계산 과정을 효율적으로 구현하는 방법을 학습했습니다.

또한 Python의 instance life cycle, 순환 참조, reference counting, GC의 동작을 살펴보며 객체의 생성과 해제가 메모리 사용에 미치는 영향을 이해했습니다. 나아가 PyTorch가 순전파 과정에서 역전파에 필요한 계산 그래프를 구성하고, 학습과 평가 과정에서 그래프 생성 및 메모리 관리 방식이 달라진다는 점을 학습했습니다.
